## 7. 测试中发现的注意事项

### 7.1 HTTP 状态码与业务码并存

错误密码、重复借阅等业务拒绝场景返回 HTTP 200，通过响应体中的非 0 `code` 表示失败。前端和后续自动化测试不能只判断 HTTP 状态码，必须同时判断统一响应业务码。

### 7.2 部分“公开命名”接口实际需要登录

`/api/announcements/published` 和 `/api/reviews/latest` 在未登录时返回 401。接口文档和前端调用处应明确携带令牌，避免把它们误认为匿名公开接口。

### 7.3 引用数据删除保护有效

存在借阅历史时直接删除测试图书会返回 HTTP 409；分类下仍有图书时删除分类会返回业务码 `2203`。这说明数据库引用保护和业务保护有效。由于系统没有对外提供删除历史借阅的清理接口，本次仅在确认精确 ID 后使用数据库事务清理测试数据。

### 7.4 代码层单元测试已同步维护

原有管理员状态测试与当前权限规则不一致。本轮已将其改为验证“超级管理员可以禁用普通管理员”，并补充“普通管理员不能禁用其他管理员”的用例。重新执行 Maven 测试后共 33 条，失败 0、错误 0、跳过 0。
